# יוסי קאר — מדריך שימוש ב-CRM

מערכת ניהול מקומית לסוכנות הרכב: מלאי, לקוחות, דיוור WhatsApp, מכירות, קופה והפקת מסמכים.

כל הנתונים נשמרים במחשב השרת בתיקיית `data/` — אין ענן.

---

## התקנה והפעלה

### דרישות
- Node.js 18+
- Chrome (ל-WhatsApp ולהפקת PDF)
- ברשת המשרד: מחשב שרת אחד שמריץ את המערכת

### הפעלה במחשב השרת
1. הרץ `RUN.bat` (השאר את החלון פתוח)
2. כתובת מקומית: `https://127.0.0.1:3000` (או `http` אם אין תעודות)
3. לעובדים ברשת: השתמש בכתובת `LAN` שמופיעה בחלון השרת, **עם https**  
   דוגמה: `https://192.168.x.x:3000`  
   לא `http` — אחרת תופיע שגיאת `ERR_EMPTY_RESPONSE`

### HTTPS (פעם אחת)
1. `setup-https.bat` במחשב השרת
2. בכל מחשב עובד: `INSTALL-TRUST.bat` (או אישור ידני בדפדפן)

### עצירה
- סגור את חלון `RUN.bat` או הרץ `STOP.bat`

## התחברות ותפקידים

- כניסה עם **תעודת זהות** + סיסמה
- **סוכן מכירות:** מלאי (צפייה/דיוור), לקוחות, WhatsApp אישי, מכירות, הפקת מסמכים
- **מנהל / בעלים:** גם נתוני סוכנות, משתמשים, ניהול, תפוצה המונית, עריכת מלאי

## מקרי שימוש נפוצים

### 1. דיוור ללקוח על רכב מהמלאי
1. מלאי רכבים ← פתיחת הרכב (פרטים)
2. התחברות ל-WhatsApp במסך **WhatsApp / שליחה** (סריקת QR בדפדפן)
3. במודאל הרכב: בחירת לקוח / נייד ידני, תמונות, הודעה
4. אופציונלי: סמן **מעוניין במימון** — מתווספת שורת המימון מהמחשבון
5. שלח ב-WhatsApp

### 2. חיבור WhatsApp לכל עובד
1. כל עובד נכנס עם המשתמש שלו
2. WhatsApp / שליחה ← **התחבר ל-WhatsApp**
3. סורקים את ה-QR שמופיע **במסך** (לא נפתח Chrome אצל העובד)
4. השליחות יוצאות מקו ה-WhatsApp של אותו עובד  
אין צורך להעתיק את הפרויקט למחשבי העובדים.

### 3. הסכם רכב חדש (PDF להדפסה)
1. תפריט **הפקת מסמכים**
2. מלא: שם מלא, ת״ז, יד הלקוח (00 / 01…), קוד דגם, יצרן, דגם
3. המערכת מוסיפה אוטומטית: **רכב חדש · 0 ק״מ · שנת 2026**
4. מספר הסכם עוקב (מתחיל ב-**236573**)
5. נפתח **PDF** להורדה / הדפסה (Ctrl+P בדפדפן)

### 4. עסקת מכירה + מסמכי עסקה
1. מכירות ← עסקה חדשה (או ממודאל רכב: «צור עסקת מכירה»)
2. בפרטי העסקה: הפקת חוזה / אישור עסקה / קבלה

### 5. קופה ודוחות
- **קופה:** רישום תשלומים
- **דוחות:** סיכומים לפי סוג (רווחיות — למנהלים)

## WhatsApp — חשוב לדעת

- סשן נפרד לכל משתמש על השרת
- QR מוצג בדפדפן של העובד
- תפוצה המונית (קהל יעד) — למנהלים בלבד
- אם השרת נפל — אף אחד ברשת לא יתחבר; הפעל מחדש עם `RUN.bat`

## פתרון תקלות מהיר

| בעיה | מה לבדוק |
|------|----------|
| `ERR_EMPTY_RESPONSE` ברשת | לפתוח **https** (לא http); לוודא ש-`RUN.bat` רץ |
| אין QR ב-WhatsApp | להתחבר מחדש במסך WhatsApp; לרענן דף |
| PDF לא נוצר | להתקין Chrome; לבדוק הודעת שגיאה אחרי ההפקה (נשמר גם HTML) |
| קטלוג יצרן ריק | סנכרון קטלוג GOV מממשק הניהול (מנהל) |

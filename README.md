# CRM_DOGMA — מדריך שימוש

מערכת CRM מקומית לסוכנות **יוסי קאר (Yossi Car)**. שם הסוכנות מוגדר ב־[`config/agency.json`](config/agency.json).

המערכת מנהלת לידים ולקוחות, מלאי רכבים, מעקבים ופגישות, מכירות, קופה, הפקת מסמכי PDF, ו־WhatsApp אישי לכל עובד.

כל הנתונים נשמרים במחשב השרת בתיקיית `data/` — אין ענן חובה.

---

## דרישות

- **Node.js 18+**
- **Chrome** (לחיבור WhatsApp ולהפקת PDF)
- Windows מומלץ (סקריפטי `RUN.bat` / `STOP.bat`)
- מחשב שרת אחד ברשת המשרד שמריץ את האפליקציה

---

## התקנה והפעלה

```powershell
npm install
```

1. הרץ `RUN.bat` (השאר את החלון פתוח) — או: `npm run dashboard`
2. כתובת מקומית: `http://127.0.0.1:3000`  
   אם הוגדרו תעודות HTTPS: `https://127.0.0.1:3000`
3. לעובדים ברשת: השתמש בכתובת ה־LAN שמופיעה בחלון השרת, **עם https** אחרי הגדרת תעודות  
   דוגמה: `https://192.168.x.x:3000`  
   בלי HTTPS ברשת עלולה להופיע `ERR_EMPTY_RESPONSE`

### HTTPS (פעם אחת)

1. במחשב השרת: `setup-https.bat`
2. בכל מחשב עובד: `INSTALL-TRUST.bat` (או אישור ידני בדפדפן)

### עצירה

סגור את חלון `RUN.bat` או הרץ `STOP.bat`.

## מקרי שימוש

### 1. ליד חדש → תחומי עניין → רכב

1. **לקוחות** ← לקוח חדש (או מקיצור בבית הנציג).
2. בפרופיל הלקוח / מגירת ליד: הוסף **תחומי עניין** (דגם, תקציב, העדפות).
3. קשר לרכב מהמלאי כשיש התאמה.
4. הגדר מעקב / פגישה עם תאריך יעד.

### 2. הקצאת ליד או פגישה לנציג

1. בפרופיל הלקוח או במגירת הליד בחר **נציג אחראי**.
2. הנציג מקבל התראה **במערכת** (פעמון).
3. אם למי שמקצה יש WhatsApp מחובר, ולנציג יש **מספר נייד** בכרטיס המשתמש — נשלחת גם הודעת WhatsApp לנציג (לפי [`config/notifications.json`](config/notifications.json)).

### 3. מעקב יומי בבית הנציג

1. מסך **בית** (דף הבית של הנציג).
2. לוח שבוע, מעקבים **להיום** ו־**באיחור**.
3. סינון: **שלי** / **כולם** / נציג ספציפי (למנהלים).
4. צבעי מקור פנייה עוזרים לזהות מאיפה הגיע הליד.

### 4. מלאי — הוספת רכב על ידי נציג

1. מבית הנציג או ממסך **מלאי רכבים** ← הוספת / עריכת רכב.
2. דיוור ללקוח ממודאל הרכב (WhatsApp) אחרי חיבור סשן.
3. ייבוא מלאי מ־Excel — רק מנהל.

### 5. דיוור ללקוח על רכב מהמלאי

1. מלאי ← פתיחת הרכב.
2. ודא חיבור WhatsApp במסך **WhatsApp / שליחה** (סריקת QR).
3. במודאל: בחירת לקוח / נייד, תמונות, הודעה.
4. אופציונלי: סמן **מעוניין במימון** — מתווספת שורת המימון מהמחשבון.
5. שלח ב־WhatsApp.

### 6. חיבור WhatsApp לכל עובד

1. כל עובד נכנס עם המשתמש שלו.
2. **WhatsApp / שליחה** ← התחבר ל־WhatsApp.
3. סורקים את ה־QR **במסך** (הסשן רץ על השרת).
4. השליחות יוצאות מקו ה־WhatsApp של אותו עובד — אין צורך להתקין את הפרויקט במחשבי העובדים.
5. **תפוצה המונית** (קהל יעד) — למנהלים בלבד.

### 7. מכירה ומסמכים

1. **מכירות** ← עסקה חדשה (או ממודאל רכב: «צור עסקת מכירה»).
2. בפרטי העסקה: חוזה / אישור עסקה / קבלה לפי הצורך.
3. תפריט **הפקת מסמכים** (`#/documents`): בחירת סוג מסמך, מילוי פרטים, הפקת PDF פנימי (עם הצהרת שימוש פנימי).
4. הסכם רכב חדש: מספר הסכם עוקב; המערכת משלימה שדות סטנדרטיים (רכב חדש, ק״מ וכו׳).

### 8. קופה ודוחות

- **קופה:** רישום תשלומים.
- **דוחות:** סיכומים לפי סוג (דוחות רגישים — למנהלים).

### 9. הגדרת נייד לנציגים (להתראות WhatsApp)

1. מנהל → **ניהול משתמשים**.
2. עדכן מספר נייד לכל נציג שצריך לקבל הקצאות ב־WhatsApp.
3. ודא ש־`whatsapp.onAssignment` מופעל ב־`config/notifications.json`.

| פעמון התראות | הקצאות ומסרים במערכת |
| נתוני הסוכנות | שם, כתובת, אתר (מנהלים) |

## התראות

| סוג | מתי |
|-----|-----|
| פעמון במערכת | הקצאת ליד / פגישה לנציג |
| WhatsApp לנציג | אותה הקצאה — דרך סשן ה־WhatsApp של מי שהקצה, אל הנייד של הנציג |
| באנרים במסך לידים | חוב פתוח, מעקב באיחור, מעקב להיום |

הגדרות: [`config/notifications.json`](config/notifications.json) — `inApp`, `whatsapp.onAssignment`, `browser` (כבוי כברירת מחדל).

## פתרון תקלות מהיר

| בעיה | מה לבדוק |
|------|----------|
| `ERR_EMPTY_RESPONSE` ברשת | לפתוח **https** (לא http); לוודא ש־`RUN.bat` רץ |
| אין QR ב־WhatsApp | התחברות מחדש במסך WhatsApp; רענון דף |
| PDF לא נוצר | להתקין Chrome; לבדוק הודעת שגיאה (לעיתים נשמר גם HTML) |
| קטלוג יצרן ריק | סנכרון קטלוג GOV מממשק הניהול (מנהל) |
| התראת WhatsApp לנציג לא נשלחת | סשן WA של המקצה מחובר; יש נייד בכרטיס הנציג; `whatsapp.onAssignment: true` |
| פורט 3000 תפוס | `STOP.bat` או `npm run stop`, ואז `RUN.bat` שוב |

# תבניות מסמכים

## מסמכי עסקה (ממסך מכירות)
המערכת מפיקה PDF בעברית (RTL) מתוך תבניות מובנות בקוד:
- `contract` — חוזה מכירה
- `order` — אישור עסקה / הזמנה
- `receipt` — קבלה פנימית (לא חשבונית מס)

קבצים נשמרים תחת `data/documents/{saleId}/`.
